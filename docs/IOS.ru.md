Это тот же прототип с десятью уровнями, управлением наклоном и вращением поля, водой, льдом и паром. Нативный расчёт жидкости собран для iOS ARM64. Минимальная версия — iOS 13.

## Установка без платного Apple Developer

Файл `hydrologic-0.16.1-ios-unsigned.ipa` не подписан сертификатом Apple. Перед установкой его нужно подписать своим Apple ID на компьютере. Открытие скачанного IPA на iPhone само по себе приложение не устанавливает.

1. Установите [Sideloadly](https://sideloadly.io/) на Mac или Windows и подключите iPhone по USB. Для Windows выполните указания Sideloadly по установке компонентов Apple.
2. Перетащите IPA в окно Sideloadly, выберите устройство и выполните подпись своим Apple ID.
3. На iPhone подтвердите доверие профилю разработчика в настройках: «Основные → VPN и управление устройством».
4. На iOS 16 и новее включите режим разработчика, если его запросит система: «Конфиденциальность и безопасность → Режим разработчика».
5. Откройте Гидрологику. Бесплатная подпись действует 7 дней; после этого приложение нужно подписать заново. Альтернатива — [AltStore Classic](https://altstore.io/).

Подпись выполняется на компьютере владельца телефона. Для TestFlight и распространения через App Store требуется платное членство Apple Developer.

## Установка через Xcode

Распакуйте `hydrologic-0.16.1-xcode.zip` на Mac, откройте `Hydrologic.xcodeproj`, выберите своё устройство и в Signing & Capabilities укажите Personal Team своего Apple ID. В проекте нет чужой команды, сертификата или профиля подготовки. При необходимости задайте собственный уникальный Bundle Identifier. Нажмите Run.

`UNSIGNED00` используется только как технический маркер для генератора Godot и удаляется из полученного Xcode-проекта перед упаковкой. Это не идентификатор Apple Developer.

## Проверка и исходная сборка

Основной выпуск предназначен для физического iPhone или iPad. Отдельная версия для iOS Simulator не входит в этот выпуск: её компоновка в текущем экспорте не прошла. Экспериментальная опция разработчика `--simulator` не требуется для сборки или установки IPA на телефон.

В репозитории есть workflow **Build iOS prototype**. Он на macOS собирает C++-библиотеку воды, выполняет 21 проверку игровой логики и управления, экспортирует проект Godot и создаёт неподписанный IPA для устройства. Карта компоновки подтверждает включение настоящего кода воды, а экспортированный конструктор Godot регистрирует его при запуске. Сведения о сборке и SHA-256 публикуются вместе с файлами.

Для сборки на своём Mac с Xcode и Python 3.11+:

```bash
export HYDRO_TOOLS="$PWD/.tools"
python3 scripts/build_ios.py
```

Скрипт использует проверенные контрольными суммами Godot 4.6.3, export templates и godot-cpp 4.5. Учётная запись Apple для создания неподписанного IPA не требуется. Проверки на Mac и проверка содержимого iPhone-бинарника не заменяют проверку акселерометра, производительности и установки на физическом iPhone.
